                   para correr. No incluye node_modules (se regenera
                   con "npm install" usando el package-lock incluido).

CÓMO CORRER EL SITIO EN 3 COMANDOS
-----------------------------------
  cd sitio
  npm install
  npm run dev
  → abrir http://localhost:3000
